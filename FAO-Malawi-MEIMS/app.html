Data Management

Initial data is seeded from the latest supplied 2026 Annual Programme Workplan, Entry hub sheet. Activity dates use the latest workbook Column M (Activity Start Date) and Column N (Activity End Date) values, and Activity Status is captured as a dedicated variable. Project-level FOUR BETTER, CPF Thematic Area and CPF Output use pull-down lists from the supplied workplan; CPF Output is dynamically filtered by the selected CPF Thematic Area.
