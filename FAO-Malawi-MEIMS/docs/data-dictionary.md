# MEIMS Data Dictionary

The master snapshot contains 19 projects and 509 activities. The exact field names and values in the JSON snapshot should be treated as the current baseline schema.

## Core activity fields
Project identification, project title, Four Betters, CPF thematic area, CPF output, project output, activity, manager, M&E focal point, approver, start date, end date, mode of implementation, districts, budget, status, progress, priority, update/comment and last-updated fields are represented in the baseline data.

## Core project fields
Project code, title, Four Betters, CPF thematic area, CPF output, manager, M&E focal point, project dates and project status are represented.

## Source alignment
The current system records activity start/end dates and mode of implementation as dedicated fields and retains the supplied project/activity information in the master snapshot.
